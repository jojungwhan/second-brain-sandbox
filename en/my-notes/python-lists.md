# Python lists

- Ordered and changeable: `nums = [3, 1, 2]`
- `nums.append(4)` adds to the end. `nums.sort()` sorts in place and returns `None`. That bit me once.
- Slicing makes a copy: `nums[:]`
- Looping: `for n in nums:`
