# Home

## Who wrote this vault

![[agent/reports/authorship]]

Refresh the numbers: `python3 tools/authorship.py --write`

## Start here

- Write a note in `my-notes/`. One idea per note.
- Write today's log in `daily/`: did, learned, still wondering.
- Start a page in `interests/` for one thing you are curious about.
- Drop a source in `inbox/` and ask the agent to ingest it.
- Add a task in `tasks/` with a due date.

## What the agent can do

- Ingest a source
- Quiz you from your own notes
- Daily log questions
- Find sources for an interest page
- Weekly review
- Vault health check

The agent never writes in `my-notes/`, `daily/` or `interests/`, and does not write schoolwork. Its rules are in `AGENTS.md`.

When the agent, its model or your plan changes, run `checks/tool-change-check.md` before you trust it with the vault.
