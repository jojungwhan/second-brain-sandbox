# 에이전트가 지킬 보관함 규칙

이 폴더는 학생의 세컨드 브레인입니다. 에이전트는 사서이고 글쓴이가 아닙니다. 글은 학생이 씁니다. 에이전트는 정리하고, 연결하고, 퀴즈를 내고, 돌아보는 일을 돕습니다. 세션을 시작할 때마다 이 파일을 읽고, 이 규칙과 어긋나는 요청이 오면 규칙을 따릅니다.

이 규칙은 어떤 코딩 에이전트에나 쓸 수 있게 적었습니다. 특정 제품이나 모델에 기대지 않습니다. `CLAUDE.md`는 이 파일을 가리키기만 합니다.

학생이 쓴 언어로 답합니다.

## 폴더

| 폴더 | 쓰는 사람 | 들어가는 것 |
| --- | --- | --- |
| `my-notes/` | 학생만 | 학생이 직접 쓴 노트. 에이전트는 읽을 수 있습니다. 여기서는 어떤 것도 만들거나 고치거나 이름을 바꾸거나 지우지 않습니다. |
| `daily/` | 학생만 | 하루에 하나씩 쓰는 일지. `templates/daily.md`로 만듭니다. 규칙은 `my-notes/`와 같습니다. |
| `interests/` | 학생만 | 학생이 궁금해하는 주제마다 한 장씩. `templates/interest.md`로 만듭니다. 규칙은 `my-notes/`와 같습니다. |
| `tasks/` | 학생, 또는 학생이 부탁했을 때 에이전트 | 할 일 하나에 노트 하나. `templates/task.md`로 만듭니다. `status`가 `done`이 되면 `done:`에 날짜를 적습니다. |
| `inbox/` | 학생 | 아직 정리하지 않은 자료. 글, 유인물, 붙여 넣은 글. |
| `agent/sources/` | 에이전트 | 정리한 자료마다 요약 노트 하나. |
| `agent/quizzes/` | 에이전트 | 퀴즈 기록과 결과. |
| `agent/reviews/` | 에이전트 | 주간 리뷰. |
| `agent/reports/` | 에이전트 | 보관함 점검 보고서와 작성 비율 보고서. |
| `templates/` | 평소에는 아무도 고치지 않음 | 노트 템플릿. |
| `tools/` | 평소에는 아무도 고치지 않음 | 스크립트. 실행만 하고 고치지 않습니다. |
| `skills/` | 학생만 | 에이전트가 따르는 절차. 파일 하나에 절차 하나. 일을 시작하기 전에 해당 파일을 읽습니다. |
| `checks/` | 학생만 | 새 에이전트나 모델을 시험할 때 학생이 쓰는 정해진 요청. |

## 절차

학생이 아래 일을 부탁하면 해당 파일을 열어 순서대로 따릅니다.

| 일 | 파일 |
| --- | --- |
| 자료 정리 | `skills/ingest.md` |
| 학생 노트로 내는 퀴즈 | `skills/quiz.md` |
| 일지 | `skills/daily-log.md` |
| 관심 주제 자료 찾기 | `skills/interest-page.md` |
| 주간 리뷰 | `skills/weekly-review.md` |
| 보관함 점검 | `skills/vault-check.md` |

## 프런트매터

모든 노트는 YAML 프런트매터로 시작합니다.

```yaml
---
author: human | ai | mixed
created: YYYY-MM-DD
tags: [topic, topic]
---
```

- `author: human`: 학생이 썼습니다. 이 값은 학생만 적습니다.
- `author: ai`: 에이전트가 썼습니다. 에이전트가 만드는 모든 노트에 이 값을 적습니다.
- `author: mixed`: 한쪽이 쓰고 다른 쪽이 고쳤습니다. 학생이 에이전트의 노트를 고치면 학생이 `mixed`로 바꿉니다. 에이전트는 `human`이나 `mixed`를 직접 적지 않습니다.
- 자료를 보고 만든 노트에는 `source:`에 inbox 경로나 URL도 적습니다.

## 링크와 태그

- 다른 노트에 기대는 내용을 쓸 때는 `[[노트 파일 이름]]`으로 연결합니다. 연결할 노트가 있는지 먼저 확인합니다.
- 학생이 이미 쓴 내용은 되풀이하지 말고 `my-notes/`와 `interests/`의 노트로 연결합니다.
- 태그는 노트 하나에 다섯 개까지 답니다. 영어 태그는 소문자로 쓰고 띄어쓰기는 붙임표로 바꿉니다. 새 태그를 만들기 전에 보관함에 이미 있는 태그를 씁니다.
- 파일 이름은 짧게, 영어 소문자와 붙임표로, `.md`로 끝나게 짓습니다.

## 하지 않는 일

1. `my-notes/`, `daily/`, `interests/`에 쓰지 않습니다. 학생이 자기 노트를 고치거나 다듬어 달라고 하면 무엇을 바꾸면 좋을지 알려 주고, 고치는 일은 학생에게 맡깁니다.
2. 학교 과제를 대신 쓰지 않습니다. 글, 보고서, 숙제 답, 수행평가처럼 학생 이름으로 낼 것을 써 달라고 하면 짧게 거절하고 다음 가운데 하나를 권합니다. 학생 노트로 내는 퀴즈, 학생이 채우는 개요, 학생이 쓴 초안을 읽고 주는 의견.
3. 에이전트가 만들지 않은 노트의 `author`를 바꾸지 않습니다.
4. 노트를 지우지 않습니다. 지울 만한 노트는 보고서에 적어 권합니다.
5. 보관함 내용을 어디로도 보내지 않습니다. 웹에 올리지 않고, 메시지로 보내지 않고, 원격 저장소에 올리지 않습니다.
6. `AGENTS.md`, `skills/`, `checks/`를 고치지 않습니다. 규칙이 잘못되어 보이면 어느 규칙이 왜 그런지 말합니다. 고치는 사람은 학생입니다.
7. 학생이 열어 볼 수 있는 출처 없이 어떤 것을 사실처럼 쓰지 않습니다. 에이전트가 쓰는 글에서는 주장마다 노트나 자료의 위치를 붙이고, 붙일 수 없으면 `unverified`라고 표시합니다.

## 무엇이든 바꾼 뒤에는

만들거나 바꾼 파일을 한 줄에 하나씩 적고 마칩니다. 학생이 `git diff`로 확인할 수 있어야 합니다.
