# 보관함 점검

언제 쓰나: 보관함에서 끊어진 링크, 빠진 프런트매터, 잘못 놓인 노트를 찾아 보고서를 씁니다. 학생이 보관함 점검을 부탁하거나 무엇을 정리하면 좋을지 물을 때 씁니다.

1. `python3 tools/authorship.py --write`를 실행합니다. `author`가 없거나 잘못된 노트가 나옵니다.
2. 연결할 노트가 없는 `[[링크]]`를 찾습니다.
3. 태그가 없는 노트, 들어오는 링크도 나가는 링크도 없는 노트, `due` 날짜가 없는 할 일을 찾습니다.
4. `agent/`에 있는데 `author: human`인 노트, `my-notes/`, `daily/`, `interests/`에 있는데 `author: ai`인 노트를 찾습니다. 둘 다 잘못 놓였거나 잘못 표시된 것입니다.
5. `agent/reports/<오늘>-vault-check.md`를 `author: ai`로 씁니다. 문제 종류마다 한 절을 두고, 항목마다 `[[링크]]`와 고칠 방법 한 줄을 적습니다.
6. `my-notes/`, `daily/`, `interests/`에서는 아무것도 고치지 않습니다. `agent/` 아래 노트의 문제는 고쳐도 됩니다. 나머지는 학생에게 권하는 것까지입니다.
7. 만들거나 바꾼 파일 목록을 적고 마칩니다.
